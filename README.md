# Workplace LMS Help Center

This project contains clear instructions for common workplace learning management system tasks.

## Who This Is For

These instructions are written for:

- Employees completing assigned training
- Supervisors checking training progress
- LMS administrators managing training records

## Available Guides

- Resetting an LMS password
- Finding assigned training
- Checking training completion
- Troubleshooting common login problems

## Project Goal

The goal of this project is to make LMS instructions easier to understand and follow.
